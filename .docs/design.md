# Интерфейс первой версии

Основная задача — быстро находить участника и вносить баллы во время школьного мероприятия. Главный экран сохраняет фирменный логотип организатора; рабочий экран отдаёт место таблице.

Палитра: фон #F3F7F7, поверхность #FFFFFF, основной текст #183C3A, действие #17675E, границы #8CA6A3, ошибка #A32525. Столбцы оценок выделены светлым #F4FAE9. Цвет не заменяет подписи и сообщения.

Шрифт Segoe UI, доступный в Windows, с кириллицей и без сетевой загрузки. Основной размер 14 px, заголовки 28 px, приветствие 36 px, часы 44 px. В формах видимые подписи, ошибки под полями, сохранение введённых значений при ошибке.

Главный экран: приветствие по центру → часы и дата → два основных действия. В нижней строке версия и «Что нового в этой версии». Крупный логотип сохраняет пропорции и приглушён белым слоем.

Экран мероприятия: возврат к списку и название → две вкладки → действия и поиск → таблица. Оценки редактируются в ячейках; сортировка и фильтрация адресуют запись по ID. Карточки используются для результатов, где они соответствуют отдельным группам зачёта.

Результаты уплотнены: командный и общий индивидуальный зачёты стоят рядом, ниже категории, команды и конкурсы образуют отдельные сетки по две карточки. При ширине сетки менее 880 px карточки переходят в одну колонку. Заголовки разделов уменьшены до 20 px, убраны повторяющиеся названия над общими зачётами. Строки призёров имеют мягкий золотистый (#FFF5D6), серебристый (#EDF2F7) и бронзовый (#FCEBDD) фон; подписи мест остаются текстовыми. ФИО и баллы выделены насыщенностью, школа и класс — вторым уровнем текста. Все разделившие место участники остаются видимыми.

Поиск навыка ui-ux-pro-max по education competition desktop предложил функциональный светлый стиль и бирюзовую палитру. Рекомендации для веб-лендинга и сетевых шрифтов не применялись к настольному приложению. Внешний вид проверен снимками обычного Windows-режима при размере 1240×800 и главного экрана 900×600; снимки offscreen не подходят для оценки шрифтов Windows.
