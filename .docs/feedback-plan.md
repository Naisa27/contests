## Обсуждение Docker, Vue 3 и CI/CD

- Пользователь напомнил, что Docker уже обсуждался; вероятный источник прежних договорённостей — feedback_hub. Первоначальный план venv + systemd для приложения не считать окончательным выбором размещения.

- Для варианта Vue 3 обсуждён единый Compose с двумя сервисами: api (FastAPI) и web (Nginx с собранными файлами Vue). Внешний Nginx завершает HTTPS, направляет /api/ в api, остальные запросы в web. Это предложенная схема, не реализованная конфигурация; Vue 3 ещё не утверждён окончательно.
- В production Vue собирается в статические файлы; Node.js и сервер разработки Vite на VDS не нужны при локальной/CI-сборке. Доступ контейнера к PostgreSQL требует отдельного проектирования: localhost контейнера не является локальным адресом хоста. Не открывать PostgreSQL всему интернету.

- Предложенный процесс: локальная разработка → CI (тесты FastAPI с отдельной PostgreSQL, проверка миграций, тесты/сборка Vue при его выборе) → выпуск версионированных Docker-образов api/web в GHCR → ручное обновление VDS пользователем по инструкции.

## Целевое поведение

- Приложение → HTTPS API → транзакционное сохранение в PostgreSQL → подтверждение с постоянным номером обращения. Успех только после сохранения.
- Обращение содержит приложение-источник, автоматически подставленную версию, сообщение, необязательные имя/контакт и время приёма.
- Идентификатор приложения не является секретом или достаточной защитой публичного API.
- Повтор после потери ответа не создаёт второе обращение; защита от дублей сохраняется после перезапуска и учитывает параллельные запросы.
- При ошибке текст остаётся в форме приложения. Локальная SQLite школьных конкурсов остаётся без изменений.
- Панель: вход владельца, список обращений, поиск и фильтры по приложению/дате/статусу, изменение статуса и внутренние заметки. Панель сама по себе не доставляет ответ пользователю.
- Предусмотреть ограничения запросов отдельно по приложениям, минимизацию хранения IP, резервные копии вне VDS и проверку восстановления. Детали реализации ещё предстоит определить.
