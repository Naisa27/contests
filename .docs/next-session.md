Локальная SQLite приложения остаётся без изменений. VDS уже есть: Ubuntu 26.04.1 LTS, Python 3.14.4, PostgreSQL 18; SSH root@129.101.106.189. Состояние проверено 13.11.2026 без изменений сервера. Дальнейшие подключения — только по отдельной команде. Полные сведения и порядок работ — в feedback-plan.md.

Целевая схема: приложение → HTTPS API → сохранение в БД → подтверждение приёма с номером обращения. Успех подтверждается только после сохранения. Каждое обращение содержит источник (приложение), его версию, сообщение и необязательные имя/контакт. Версия уже подставляется клиентом автоматически, спрашивать её в форме не нужно. При ошибке текст остаётся в форме. Идентификатор приложения не является секретом или достаточной защитой API. Детали API и схемы БД предстоит определить при появлении сервера.

Обработка обращений — на внешнем сервере. В первой версии уведомления только в веб-панели, без почты и Telegram; ответы пока вручную по оставленному контакту. Предусмотреть защиту от дублей, отдельные ограничения по приложениям, резервные копии вне сервера и проверку восстановления. Рекомендация минимизировать передачу IP обсуждалась, изменение ещё не реализовано.

Личная веб-панель с авторизацией входит в первую версию: все обращения, фильтры по приложению/дате/статусу, статусы обработки, внутренние заметки. Vue 3 рассматривается, но окончательно не утверждён; Jinja2 также не утверждён. API отделяется от интерфейса. Панель сама по себе не доставляет ответ. БД, панель и новые механизмы ещё не реализованы.
