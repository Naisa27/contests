# Состояние реализации

Дата: 09.11.2026. Текущая версия: 0.1.1.

После первой сборки исправлено начальное размещение главного окна: центрирование в рабочей области собственного монитора после определения рамки Windows, уменьшение под доступный размер, без повторного центрирования после ручного перемещения. Проверено обычным Windows-запуском; текущие 34 теста проходят, включая отрицательные координаты дополнительных мониторов. Сборки в dist относятся к состоянию до этого исправления; для проверки изменения запускать uv run school-contests.

Следующее изменение исходников: результаты вынесены в ui/results.py; по две карточки в строке на широком экране, одна на узком, цветные строки мест (золото/серебро/бронза). Проверены реальные снимки Windows при 1240×800 и 900×600. Текущие 35 тестов проходят, включая переход 2 → 1 → 2 колонок, длинные ФИО и сохранение всех участников с одинаковым местом. Установщик и переносной ZIP с этими изменениями пока не пересобраны.

Добавлена колонка «ИТОГО» в таблице участников при наличии конкурсов. Сумма обновляется после сохранения/очистки балла, выделена фоном и полужирным шрифтом, недоступна для редактирования; сортировка числовая и обновляется при изменении оценки. При удалении последнего конкурса колонка исчезает. Проверки: 37 тестов проходят. Изменение пока доступно при запуске из исходников, сборки не пересобраны.

Справа от поиска по ФИО добавлен фильтр категории с вариантами «Все категории» и представленными категориями мероприятия. Фильтры работают совместно; после добавления/импорта и изменения участников список автоматически обновляется. Проверки: 39 тестов проходят, включая ввод оценки нужному участнику при обоих фильтрах и обновление вариантов после изменения категории. Сборки в dist пока прежние.

Экран «Все мероприятия» переделан в таблицу с колонками даты, названия и организатора. Добавлена подсказка «Выберите нужное мероприятие»; кнопки открытия и редактирования включаются только после выделения строки. Даты показаны в формате ДД.ММ.ГГГГ и сортируются хронологически, открытие адресуется по ID выбранной строки. Проверено в Windows до и после выбора; 41 тест проходит. Сборки не пересобраны.

После публикации исходников в GitHub и повторной сборки 0.1.0 добавлен путеводитель для учителей и организаторов: постоянная кнопка справа вверху, оглавление из 11 тем, навигация «Назад»/«Далее», читаемый прокручиваемый текст. Текст — пакетный resources/guide.md, окно — ui/guide.py; гайд работает без сети и включается существующим сценарием сборки ресурсов. Описаны подготовка мероприятия, конкурсы, команды, ручной ввод и Excel, баллы, пять зачётов, экспорт, резервные копии и частые вопросы. Проверены снимки Windows, открытие с основных экранов и навигация; 43 теста проходят. Сборки в dist пока без путеводителя.

По запросу пользователя подготовлен выпуск 0.1.1. Версия обновлена в пакете, pyproject.toml и uv.lock; окно «Что нового» описывает путеводитель. Выполнены чистая сборка PyInstaller, создание переносного ZIP и компиляция Inno Setup. В папку приложения также включён отдельный Путеводитель.md; ссылка на него в Инструкция.md адаптирована для локальной поставки. Установщику явно заданы VersionInfoVersion и VersionInfoProductVersion, чтобы в свойствах Windows показывалась версия 0.1.1 вместо значения по умолчанию 0.0.0.0.

Проверки выпуска 0.1.1: 43 теста проходят; готовый exe открывается на отдельной тестовой базе, штатно закрывается и снимает блокировку. scripts/verify_release.py подтверждает версию пакета, exe и установщика, наличие окна путеводителя и актуальных текстовых ресурсов, целостность ZIP и переносной маркер. Артефакты: dist/SchoolContests-0.1.1-setup.exe (43,4 МиБ) и dist/SchoolContests-0.1.1-portable.zip (60,7 МиБ). Журналы: .local/build-0.1.1.log и .local/installer-0.1.1.log. Реальная установка и обновление на чистой Windows не проверялись. Изменения версии и сборочных файлов включены в коммит выпуска 0.1.1; установщик и переносной ZIP остаются локальными артефактами в dist.

Созданы структура src/school_contests, pyproject.toml, окружение uv Python 3.14 и uv.lock. Инициализирован локальный Git-репозиторий для исходников, тестов, документации и настроек проекта. Локальные базы данных, окружение и сборки исключены из Git.

Реализованы:

- Главный экран с приглушённым логотипом, местными часами и датой, навигацией, текущей версией и окном «Что нового в этой версии».
- Создание и редактирование мероприятий, конкурсов и команд; добавление и редактирование участников.
- Таблица QTableView/QAbstractTableModel с поиском без учёта регистра, сортировкой и вводом баллов по ID.
- Назначение команды до первого балла, запрет дробей и отрицательных чисел, различение пустой оценки и явного нуля.
- SQLAlchemy Core + SQLite, внешние ключи и ограничения, транзакции с атомарным перерасчётом сохранённых результатов.
- Пять зачётов, три лучших различных результата с разделением мест, карточки и отметка о предварительных результатах.
- Excel-шаблон, редактируемый предпросмотр импорта с исключением строк, проверкой дублей и конфликтов названий команд; транзакционный импорт.
- Экспорт участников и оценок плюс пять листов результатов всего мероприятия.
- Фоновые Qt-потоки для чтения/записи Excel, импорта и резервных операций.
- Резервное копирование, проверка и восстановление с автоматической копией текущей БД; блокировка одновременного открытия одной БД.
- Пакетные логотип, сгенерированная PNG-иконка и ICO 16/24/32/48/64/128/256.
- Скрипт PyInstaller onedir, переносной ZIP с portable.flag, Inno Setup для текущего пользователя.
- Установщик различает установку, переустановку и обновление, показывает обе версии при обновлении и запрещает понижение версии.

Автоматические проверки: 29 тестов проходят. Покрыты расчёт мест, категории, ввод баллов, различие пустого значения и нуля, принадлежность мероприятию, транзакционный откат, импорт/экспорт, резервное восстановление, фильтрация и сортировка, фоновая операция без блокировки цикла событий, очистка заполненной числовой ячейки через реальный редактор Qt.

Визуально проверены снимки обычного Windows-режима: главный экран 1240×800 и 900×600, таблица, результаты, «Что нового», форма участника и предпросмотр импорта. Проверены размеры ICO 16–256 и различимость малых размеров на светлом/тёмном фоне. Снимки находятся в .local/preview.

Окончательная чистая сборка PyInstaller и Inno Setup завершена. Проверка scripts/verify_release.py подтвердила актуальные модули (включая редактор очистки оценок, тему и предпросмотр), пакетные ресурсы, номер версии exe, целостность ZIP и правильное размещение portable.flag. Повторный запуск готового exe на отдельной базе подтвердил появление главного окна, создание корректной БД, штатное закрытие и снятие блокировки.

Артефакты в dist:

- SchoolContests/SchoolContests.exe — приложение в режиме onedir; для переноса нужна вся папка.
- SchoolContests-0.1.0-portable.zip — переносной комплект, 60,7 МиБ.
- SchoolContests-0.1.0-setup.exe — установщик, 43,4 МиБ.

Сборка всегда выполняется с --clean, чтобы исключить устаревшие модули из кэша PyInstaller. Последний журнал — .local/build-clean.log. Реальная установка, переустановка и обновление на чистой Windows в этой сессии не выполнялись; сценарий установщика успешно скомпилирован.

Перед распространением: проверить установку и обновление на отдельной чистой Windows без Python и Excel, сохранение реальных пользовательских данных, масштаб 150–200%, ярлыки и значок в панели задач. Подпись установщика и exe не настроена.

Команды запуска и сборки — в README.md. Демонстрационная база и снимки находятся только в .local/preview; пользовательская база в разработке создаётся отдельно в .local/contests.sqlite3.
