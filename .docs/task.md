# Проведение конкурсов

Десктопное Windows-приложение на Python для управления школьными конкурсами

## Стек
- Python 3.14
- **GUI**: PySide6
- **БД**: SQLite (файл внутри проекта) + SQLAlchemy Core
- **Excel чтение**
- **Сборка**: PyInstaller + установщик Inno Setup 6
конечный продукт должен быть скомпилирован в exe для использования на локальных машинах пользователей. Предполагается, что все пользователи будут работать с ОС Windows
- **Тесты**: `pytest`
- **Менеджер пакетов**: `uv` — управление зависимостями и виртуальным окружением через `pyproject.toml` + `uv.lock`


## Назначение проекта
Приложение для учителей/организаторов для проведения различных конкурсов в школах. 
Программа позволяет внести участников конкурса вручную или/и загрузкой из Екселя. Создать несколько конкурсов внутри одного конкурсного мероприятия, указать количество баллов по каждому участнику. На выходе получить список финалистов в командном зачёте, в индивидуальном зачёте, в каждой категории и другие варианты награждений победителей. 

## модель работы приложения
на главной странице 2 кнопки: Создать новое конкурсное мероприятие и посмотреть все существующие.
При создании: даётся название, дата начала, организатор
При просмотре возможность добавить участников как методом заливки из екселя, так и вручную. Для добавления вручную открывается дополнительное окно с полями для заполнения.
необходимые данные участника:
- Фамилия Имя
- номер школы, город школы (289 СПб, 193 Москва, 5 Калининград и т.п.)
- номер класса (1а, 2б, 9в и т.п.)
- категория класса (1, 2 ... 11)
- номер команды

внутри созданного мероприятия создаётся конкурс. Ему присваивается название.

для проведения конкурса формируется табллица со всеми участниками. Вверху поле поиска по ФИО участника, чтобы быстро отфильтровать строку по нужному ФИО. 
В таблице также выводятся столбцы для каждого созданного конкурса. В эти поля оорганизатор вписывает количество баллов по каждому участнику в течение проведения мероприятия. По итогам каждого внесения сразу идёт перерасчёт данных.
На соседнем табе формируются результаты. Командный зачёт - команды-финалисты, индивидуальный зачёт - ФИО финалистов без привязки к командам и категориям, индивидуальный зачёт в рамках своей категории - ФИО финалистов в каждой категории классов, индивидуальный зачёт в рамках своей команды - ФИО финалистов в каждой команде, Индивидуальный зачёт по каждому конкурсу - ФИО финалистов по каждому конкурсу отдельно.
Финалисты всегда распределяются по 1, 2 и 3 месмтам. Если у двух участников одинаковое количество баллов и оно попадает в финал, то эти участники разделяют одно место  в финале. То есть финалистов может быть более 3-х. Может быть несколько человек, занявших 1-е или 2-е или 3-е место в любом из зачётов.


## Хранение данных
в БД. А БД хранится рядом с приложением, например. Предложи варианты исходя из того, что будет происходить установка приложения на винду и там могут быть какие-то ограничения.
в БД будут храниться все созданные мероприятия и конкурсы внутри них. А также все результаты конкурсов и список финалистов.


## UI
на главном экране 2 кнопки, как описано в модели работы приложения.

При нажатии на "создать" открывается экран с полями "название", "дата начала мероприятия", "организатор"
После их заполнения открывается экран просмотра мероприятия.
На нем 2 таба:
1. проведение конкурса
2. результаты конкурса

на 1-м таблица со следующими полями:
- команда
- Фамилия Имя
- Школа
- Класс
- категория класса
- столбцы с названиями конкурсов

поля в столбцах с конкурсами должны иметь возможность редактироваться, туда будут вносить цифры

над таблицей поле поиска по ФИО участника. При внесении в него текста сразу фильтруется таблица по внесенным буквам.

При двойном клике на ФИО ( либо сделать ярлычок в виде карандаша в правом углу поля) открывается форма для корректировки данных участника. В ней поля "Фамилия Имя", "Школа", "класс", "категория класса". Все поля открыты для редактирования. При внесении изменений и закрытии формы эти изменения сразу отображаются в основной таблице.

При переходе на второй таб с результатами идёт расчёт всех данных для этого таба на основе внесенных данных в столбцах конкурсов.
Для каждого вида зачёта карточка с финалистами и их результатами.

### Командный зачёт
сумма всех баллов по всем конкурсам внутри каждой команды.
сравниваются суммы балов команд.
одна карточка:
место - название команды - количество баллов

### индивидуальный зачёт
сумма всех баллов по каждому участнику отдельно
сравниваются суммы баллов каждого участника
одна карточка:
место - ФИО участника - количество баллов

### индивидуальный зачёт в рамках своей категории
сумма всех баллов по каждому участнику внутри каждой категории
сравниваются суммы баллов каждого участника в каждой категории отдельно
количество карточек = количеству категорий класса:
место - ФИО участника - количество баллов

### индивидуальный зачёт в рамках своей команды
сумма всех баллов по каждому участнику внутри каждой команды
сравниваются суммы баллов каждого участника в каждой команде
количество карточек = количеству команд:
место - ФИО участника - количество баллов

### индивидуальный зачёт по каждому конкурсу
сравниваются суммы баллов каждого участника внутри каждого конкурса отдельно
количество карточек = количеству конкурсов:
место - ФИО участника - количество баллов
