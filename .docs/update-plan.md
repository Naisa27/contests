# План уведомлений о новых версиях

Дата фиксации: 18.11.2026.

Статус: согласован как будущая доработка. По прямому указанию пользователя сейчас только сохранить план, ничего не реализовывать. Проверка обновлений в приложение не добавлена; версия 0.2.1 остаётся без этой функции.

## Поведение приложения

- После открытия главного окна проверять обновления в фоне, не чаще одного раза в сутки, без задержки запуска и блокировки работы.
- Добавить пункт «Справка → Проверить обновления» для проверки вручную.
- При обнаружении новой версии показывать установленную и доступную версии, краткое описание изменений, кнопки «Скачать обновление» и «Напомнить позже».
- «Скачать обновление» открывает ссылку на установщик в браузере. Пользователь самостоятельно скачивает файл, закрывает приложение и устанавливает обновление.
- «Напомнить позже» закрывает уведомление; повторное автоматическое предложение возможно при следующей проверке по суточному интервалу.
- При автоматической проверке ошибки сети не показывать. При ручной сообщать о недоступности проверки либо об отсутствии обновлений.

## Реализация при отдельном запросе

- Источник по умолчанию — последний стабильный выпуск публичного GitHub Releases; адрес репозитория вынести в конфигурацию. Публикация релизов и выбор публичного репозитория ещё не выполнены.
- Сравнивать числовые части версий: 0.2.10 новее 0.2.9. Предварительные выпуски не предлагать.
- Использовать асинхронный сетевой запрос Qt с тайм-аутом 10 секунд; исключить одновременные проверки.
- Время последней автоматической попытки сохранять локально через QSettings. Ручная проверка обходит суточный интервал.
- Автоматическое скачивание и запуск установщика в эту доработку не входят.

## Проверки и условия выпуска

- Проверить новую, текущую и более старую опубликованную версию, отсутствие интернета, тайм-аут и некорректный ответ.
- Проверить суточный интервал, ручную проверку, открытие ссылки, «Напомнить позже» и закрытие приложения во время запроса.
- Перед включением функции опубликовать стабильный релиз с установщиком в публичном репозитории. Для скачивания пользователям не должны требоваться аккаунт и вход в GitHub.
- Уже выпущенная версия 0.2.1 уведомлений не получит: пользователям потребуется один раз вручную установить версию с этой функцией.
- До отдельного запроса на реализацию не изменять код, зависимости и сборки ради этой функции и не публиковать релизы.
