# Школьные конкурсы

Настольное приложение для Windows, которое помогает учителям и организаторам проводить школьные конкурсы и подводить итоги. Работает локально, данные сохраняются в SQLite.

## Возможности

- Мероприятия, конкурсы, команды и участники.
- Ввод баллов в таблице с автоматическим подсчётом итоговой суммы.
- Поиск по ФИО и фильтр по категории.
- Пять видов зачёта с разделением одинаковых призовых мест.
- Импорт участников из Excel с предпросмотром и экспорт результатов.
- Резервное копирование и восстановление данных.

**Стек:** Python 3.14, PySide6, SQLite, SQLAlchemy Core, openpyxl.

## Запуск

Требуются Windows, [uv](https://docs.astral.sh/uv/getting-started/installation/) и Python 3.14. Репозиторий можно клонировать по SSH:

```powershell
git clone git@github.com:Naisa27/contests.git
cd contests
uv sync --locked
uv run school-contests
```

При запуске из исходников база находится в `.local/contests.sqlite3` внутри проекта и не отправляется в Git. Microsoft Excel для импорта и экспорта не требуется.
