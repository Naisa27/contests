# Школьные конкурсы

Локальное Windows-приложение для учителей и организаторов. Интернет, Microsoft Excel и Python пользователю установленной версии не нужны.

Пошаговый [путеводитель для учителей и организаторов](../src/school_contests/resources/guide.md) доступен и внутри приложения: кнопка «Путеводитель по приложению» постоянно расположена справа вверху. В нём есть оглавление, кнопки «Назад» и «Далее», инструкции по подготовке и проведению мероприятия, Excel, результатам и резервным копиям.

## Запуск из исходников

Требуются uv и Python 3.14.

```powershell
uv sync
uv run school-contests
```

## Работа

1. Создайте мероприятие, укажите название, дату и организатора.
2. Добавьте конкурсы и команды соответствующими кнопками.
3. Добавьте участников вручную или скачайте шаблон Excel, заполните и импортируйте его. В предпросмотре исправьте ошибки, задайте единое название для каждого номера команды; ненужные строки исключите отметкой.
4. Вносите целые неотрицательные баллы в столбцах конкурсов. Перед первым баллом участнику нужно назначить команду. Пустая ячейка считается нулём, но отличается от введённого «0»; для очистки удалите содержимое ячейки и подтвердите ввод.
5. На вкладке результатов доступны пять видов зачёта. Призовые места — три лучших различных результата, при равенстве баллов место делится.
6. Экспорт Excel сохраняет всё мероприятие независимо от поиска: участников с баллами и пять листов результатов.

Двойной щелчок по ФИО открывает форму участника. Название команды меняется в окне «Команды». На главном экране доступны часы и «Что нового в этой версии».

## Данные и резервные копии

Все изменения сохраняются автоматически. Установленная версия использует `%LOCALAPPDATA%\SchoolContests\data\contests.sqlite3`, переносная — `data\contests.sqlite3` рядом с exe. В разработке база находится в `.local/contests.sqlite3`. Для отдельной базы можно задать переменную окружения `SCHOOL_CONTESTS_DATA` с полным путём к файлу.

Меню «Данные» позволяет сохранить резервную копию и восстановить её. Перед восстановлением рядом с текущей базой автоматически создаётся копия `before-restore-*.sqlite3`. Одна база открывается только одним экземпляром приложения. Обновление и удаление установленного приложения не удаляют базу пользователя.

## Проверка и сборка

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
uv run pytest -q
uv run python scripts/build.py --installer
```

Для проверки запуска собранного exe на отдельной базе выполните `uv run python scripts/smoke_exe.py`. Скрипт кратко открывает главное окно и штатно закрывает его. Проверочные снимки интерфейса создаются командой `uv run python scripts/preview.py` в `.local/preview`; на Windows используйте `QT_QPA_PLATFORM=windows`, чтобы шрифты отображались корректно.

Для установщика требуется Inno Setup 6. В `dist` появятся папка `SchoolContests`, переносной ZIP и установщик. Для переноса распакуйте ZIP целиком и запустите `SchoolContests.exe`. При использовании папки onedir без ZIP режим установки выбирается по наличию `portable.flag`: добавьте пустой файл для переносного режима.

Номер выпуска задаётся в `src/school_contests/__init__.py` и `pyproject.toml`; текст изменений — в пакетном `resources/changes.txt`. Скрипт сборки берёт номер из пакета для exe и установщика. Установщик показывает первую установку, переустановку или переход между версиями до копирования файлов. Установка более старой версии поверх новой запрещена.

Перед распространением требуется отдельная проверка установщика и обновления на чистой Windows без Python, а также проверка масштаба 125–200%. Локальная сборка не заменяет эту проверку.
